### 🔬 RetinaFalcon-Net | Deep Learning for Eye Health

This project explores how deep learning can be applied to retinal image analysis. It focuses on classifying diabetic retinopathy into five categories, ranging from healthy retinas to advanced stages of the condition.

**Project highlights**
- Preparing retinal images for analysis
- Exploring image feature extraction and classification
- Applying deep learning techniques to medical images
- Presenting predicted categories through a web interface

**Classification categories:** Healthy · Mild · Moderate · Severe · Proliferative DR

**Built using:** Python · Deep Learning · CNN · RCNN · RNN · Flask
